# 基础英语表达的进阶词汇替换

Date: 2026-05-13  
Category: english-writing

## 内容概要

本篇笔记整理了可用于替换 "very good"、"very bad"、"not clear" 或 "required" 等基础表达的进阶词汇。其目的在于使写作与口语表达更加精准、地道，且便于日后系统复习。

## 核心要点

- 许多 "very + 形容词" 的结构都可以用一个更有力量的进阶单词直接替换。
- 部分进阶词汇具有正式、敏感或特定语境要求，因此掌握用法细节至关重要。
- 清单按照语义主题进行分组，以便后续针对性复习。

## 决策与结论

- 将本篇作为英语词汇复习笔记归入 `english-writing` 类别。
- 采用分组表格的形式呈现，替代单调冗长的原始清单。

## 待定问题

- 无。

## Sensitive Or Context-Specific Words

| 词汇 | 使用注意事项 |
| --- | --- |
| obese | 通常属于医学术语，日常随口形容他人可能会显得失礼。 |
| destitute | 语气强烈的赤贫词汇，强调极度匮乏，不单单是指「不富裕」。 |
| infamous | 仅用于负面名声（臭名昭著）。切勿用来形容正面意义上的名人。 |
| derogatory | 专指侮辱性、贬损性的言辞，尤其针对特定个人或群体。 |
| amateur | 可作中性词（业余爱好者），但若用于评价他人的专业水准，常带有贬义。 |
| delinquent | 视语境而定，既可指拖欠付款（逾期），也可指青少年违法犯罪行为。 |
